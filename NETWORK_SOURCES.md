## Link and content decisions

- AstraZeneca's old Read More link incorrectly led to the Nanjing Centre. Its card now links to https://www.astrazeneca.com/ and identifies the group/contact from the original listing; no additional partnership specifics were inferred.
- The original CAM-SU GRC link is preserved: https://cam-su.medical.suda.edu.cn/cms/343601.html. The institution's server could not be reached by the retrieval tool during review, so its current page contents are not independently verified.
- CIPF's current group pages and postal code (46024) take precedence over older links and address details on the original lab page. Related groups are presented separately, not as a fabricated unified staff roster.
- The Nanjing original page contains historical forward-looking construction language. This was not restated as a current event. Programme summaries use the Centre's project page instead.
- Media, seminar and MPhil/alumni archive entries link to their original pages and are explicitly labelled “Original website”. The new navigation retains access without implying those archives have been migrated.
- No collaborators, biographies, achievements or project dates were invented. Photos are described as original lab archive images rather than evidence of a current complete team roster.

## Maintenance

Edit the English HTML and `data/network-i18n.json` for page copy. `scripts/build_navigation.py` applies shared navigation to all English pages; run `scripts/build_zh.py` afterwards to rebuild Chinese pages. New local styles/scripts must be included in the translator's relative-path list. People role links use the existing filter data, and the institution tabs retain static full content when JavaScript is unavailable.
